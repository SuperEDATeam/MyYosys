# Yosys 实时语法高亮测试用例

## 一、编译测试

### TC-01: 编译通过
- **步骤**: 在 Visual Studio 中执行"重新生成解决方案"
- **预期**: 0 个编译错误，警告可以忽略
- **如果不通过**: 请把错误截图发给我

---

## 二、基础交互功能测试

### TC-02: 程序能正常启动并进入交互模式
- **步骤**: 运行 `MyVSYosys.exe`
- **预期**: 出现 yosys 欢迎横幅，最后一行显示 `yosys>` 提示符

### TC-03: 方向键编辑
- **步骤**:
  1. 输入 `help`
  2. 按 `←` 左方向键，光标移到 `p` 和 `l` 之间
  3. 输入 `ful`，变成 `helpful`
  4. 按 `→` 移到行尾
  5. 按 `Backspace` 删除 `l`
- **预期**: 光标能正常左右移动，插入和删除字符时不会增加新行

### TC-04: 上下键历史记录
- **步骤**:
  1. 输入 `help` 并按回车
  2. 输入 `stat` 并按回车
  3. 按 `↑` 上方向键两次
  4. 按 `↓` 下方向键一次
- **预期**:
  - 第一次 `↑` 显示 `stat`
  - 第二次 `↑` 显示 `help`
  - 按 `↓` 回到 `stat`

### TC-05: Tab 命令补全
- **步骤**:
  1. 输入 `re` 并按 `Tab`
  2. 输入 `read_veri` 并按 `Tab`
- **预期**:
  - 第一次按 `Tab` 出现补全菜单（包含 `read_verilog`, `read_rtlil`, `read_aiger` 等）
  - 第二次按 `Tab` 自动补全为 `read_verilog`

### TC-06: Tab 对象补全（非 read_/write_ 命令）
- **步骤**:
  1. 运行 `read_verilog your_test.v` 加载一个设计
  2. 输入 `select `（注意后面有个空格），然后按 `Tab`
- **预期**: 出现当前模块内的信号/实例名称补全菜单

### TC-07: Ctrl+D / exit 退出
- **步骤**:
  1. 按 `Ctrl+D`
  2. 重新运行，输入 `exit` 并按回车
- **预期**: 两种方式都能正常退出程序

---

## 三、语法高亮测试（核心功能）

### TC-08: 命令关键字高亮
- **步骤**: 在提示符处输入 `help`
- **预期**: `help` 显示为 **亮黄色加粗** (`#F9F1A5 bold`)

### TC-09: 参数/选项高亮
- **步骤**: 输入 `read_verilog -formal`
- **预期**:
  - `read_verilog` → 亮黄色加粗
  - `-formal` → 浅灰色 (`#CCCCCC`)

### TC-10: 字符串/文件名高亮
- **步骤**: 输入 `read_verilog "test.v"`
- **预期**:
  - `read_verilog` → 亮黄色加粗
  - `"test.v"` → 纯白色 (`#FFFFFF`)

### TC-11: 注释高亮
- **步骤**: 输入 `# this is a comment`
- **预期**: 整行显示为深灰色 (`#808080`)

### TC-12: 多 token 混合高亮
- **步骤**: 输入 `synth_ice40 -top mytop -json out.json`
- **预期**:
  - `synth_ice40` → 亮黄色加粗
  - `-top` → 浅灰色
  - `mytop` → 白色
  - `-json` → 浅灰色
  - `out.json` → 白色

### TC-13: 数字高亮
- **步骤**: 输入 `select 0`
- **预期**: `0` 显示为白色 (`#FFFFFF`)

### TC-14: 空输入无异常
- **步骤**: 直接按回车
- **预期**: 无报错，不增加历史记录，显示新提示符

### TC-15: 错误命令高亮
- **步骤**: 输入 `not_a_command`
- **预期**: `not_a_command` 显示为白色（不是已注册命令，所以不高亮为黄色）

### TC-16: 分号分隔多命令（高亮限制说明）
- **步骤**: 输入 `help; stat`
- **预期**:
  - `help` → 亮黄色加粗（第一个命令）
  - `stat` → 白色（当前实现只高亮行首命令；这是已知限制，后续可优化）

## 五、边界与稳定性测试

### TC-17: 长命令输入
- **步骤**: 输入一个很长的命令（超过 80 个字符）
- **预期**: 光标自动换行，编辑和高亮正常工作，回车能正确执行

### TC-18: 中文/Unicode 文件名
- **步骤**: 输入 `read_verilog "测试.v"`
- **预期**: 中文字符正确显示，高亮逻辑不崩溃（字符串高亮应覆盖 `"测试.v"`）

### TC-19: 递归 shell
- **步骤**:
  1. 输入 `shell`
  2. 看到新的 `yosys>` 提示符
  3. 输入 `exit`
- **预期**: 能进入子 shell 并正常返回上一层

### TC-20: 历史持久化
- **步骤**:
  1. 输入几条命令：`help`, `stat`, `synth`
  2. 退出程序
  3. 重新运行程序
  4. 按 `↑`
- **预期**: 能看到上次的命令历史
